# Demo script

1. Start the API and frontend using the README commands.
2. Sign in as `student@medpath.local` and show the seeded course, dashboard metrics and lesson completion.
3. Open the AI Study Assistant from the course workflow and point out the `isMock`/educational-only boundary.
4. Sign out and sign in as `educator@medpath.local`; create a course from Course builder.
5. Sign in as `admin@medpath.local`; show Users and Audit log. Explain that authorization is enforced server-side, not just hidden in the UI.
6. Open `/swagger` and `/health` to demonstrate the operational surface.
